---

Portfólio desenvolvido como parte do desafio da Digital Innovation One (DIO),curso **Formação JavaScript Developer** estruturado com arquitetura baseada em JSON e estilização modularizada.

## 🚀 Acesse o Projeto
Você pode acessar a versão ao vivo do portfólio através do link:
👉 [Portifólio Higor de Campos](https://higorcamposgit.github.io/Publicando-Seu-Portfolio-Profissional-no-GitHub-Pages/))

---

**Descrição dos principais arquivos**
`index.html`: estrutura principal da página.
`assets/css/`: estilos da interface.
`assets/js/`: scripts para carregamento e renderização dos dados.
`data/profile`.`json`: arquivo contendo as informações do perfil (`nome`, `sobre`, `cargo`, `localização`, `habilidades`, `experiência`, etc.)
`data/imgs/`: imagens e logos dos ícones de tecnologias.
`assets/img/`: imagem de perfil e outros assets visuais.

---
**Funcionalidades**
-Layout responsivo.
-Seções expansíveis (`accordion`).
-Dados dinâmicos carregados via `JSON`.
-Apresentação profissional em estilo portfólio.
-Fácil manutenção e personalização.
